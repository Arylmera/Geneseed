- **The session context no longer carries a rule's `source:` audit trail.** Each rule in `user-rules.md` ends its metadata line with who said it, when, and their words. The model does not need that to obey the rule, and on a real file it was 12% of the text, enough to push the profile, wiki and memory map out of the 9 000-character session budget. The injected text on Claude Code and OpenCode now shows `(scope: global)` or `(scope: global | trial until: 2026-12-18)`; `scope:` and `trial until:` change how a rule applies and stay. The file itself is never rewritten.
