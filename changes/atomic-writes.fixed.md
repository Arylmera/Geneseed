- **One atomic writer, and a prune that clears the folders it empties.** The install manifest and every JSON config write now go through `writeTextAtomic`: a pid-tagged temp file, the Windows rename retry, and the temp file removed on any failure. The manifest writer used to keep a fixed `.tmp` name, never retried, and left that file behind when the rename failed. A re-emit also removes every directory a stale file empties, so a dropped `skills/<name>/references/x.md` no longer leaves an empty `skills/<name>/`.
