usage: harness uninstall [-h] [--target TARGET] [--yes] [--archive-memory]

options:
  -h, --help        show this help message and exit
  --target TARGET   repo (project scope) or config dir (global scope) to
                    uninstall from; default: the cwd if it holds a project
                    install, else the OpenCode global config dir
  --yes             skip the confirmation prompt
  --archive-memory  move the memory and notebook stores aside to sibling
                    archived-memory/ + archived-notebook/ <timestamp> dirs
                    (never deleted; default keeps them in place)
